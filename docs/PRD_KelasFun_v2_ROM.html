🔒 4 — Security & Lisensi (P0)

Device Binding Real

  • device_info_plus 11.1.0 → androidId / iosIpad / windows DeviceId + hash SHA256(salt+id)
  • Format tetap KFUN-XXXX-XX kompatibel serial_generator.html — cuma deviceId inputnya yang real
  • AuthGate: validateCode(deviceId) + Supabase validate_license() jika online, else cek local + graceUntil = activatedAt+30d

Supabase

  • Hapus hardcode di app_config.dart → --dart-define=SUPABASE_URL/ANON_KEY + obfuscate --split-debug-info
  • RLS: licenses INSERT hanya service_role, anon cuma rpc validate_license
  • Admin panel: hapus service_role dari JS, pakai Edge Function proxy

Lynk Webhook

  • Verify x-lynk-signature == sha256(amount+refId+msgId+secret) — reject 401 jika mismatch
  • Generate key XXXX-XXXX-XXXX-XXXX + insert buyer_email, purchase_ref_id
  • Email via Resend: template navy+gold konsisten

Sync 8080

  • x-api-key wajib di semua route termasuk /api/health
  • Key = crypto.random 32 hex generate di laptop, QR pairing bawa key + IP + port
  • Simpan encrypt via flutter_secure_storage bukan plain SharedPreferences
Lihat flow lisensi end-to-end (klik)
Guru buka app → Device ID KF-ABCD1234 → WA seller → Seller buka serial_generator.html → paste → KFUN-RX7P-Q2 → Guru tempel → SerialService.validateCode(local OK) → jika online supabase.rpc(validate_license) → license_valid=true + graceUntil → masuk Dashboard. Offline tetap bisa 30 hari.
